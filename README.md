# AI-Powered Blog Application

This project is an AI-powered blogging platform developed using Django.
It allows users to create blog posts efficiently with the help of AI-based
features such as automatic title generation and grammar correction.

## Features
- User authentication and authorization
- Voice-to-text blog creation
- AI-powered grammar correction
- Automatic blog title generation
- Secure and user-friendly interface

## Tech Stack
- Python
- Django
- OpenRouter API (Mistral 7B)
- HTML, CSS, JavaScript
- SQLite

## Project Architecture
The application follows a modular Django architecture with separate
components for authentication, blog management, and AI processing.
User input is processed through the AI module to enhance content quality
before storage and display.

## Future Enhancements
- Deployment to cloud platforms
- Improved AI content suggestions
- User analytics and dashboard features
